Memory Palace

Remember which word was in which location.

Get PuzzlestackThe 1.1.0 release is finishing. The source is public today.

How to play

Tap the locations in the room and select the correct item from the list.

  1. Observe the items placed at various locations in the room.
  2. Create a mental story linking the item to the location.
  3. Once the items are hidden, tap a location.
  4. Select the item that belongs there from the options.

Strategy

  • Make your mental associations weird or funny—they are easier to remember.
  • Visualize walking through the room in a specific path.

What it asks of you

Associate items with specific locations in a room and recall them later.

Questions

Is Memory Palace free?

Yes. Puzzlestack is free to download, with no advertising, no account and nothing collected about you. Every puzzle can be played at least once.

How long does one Memory Palace take?

A few minutes at the size it opens; bigger boards are in the library.

Do I have to guess in Memory Palace?

No. Where a puzzle has one answer, the generator proves it before dealing, and the clues are enough to get there by reasoning.

What does Memory Palace practice?

It is a memory puzzle: associate items with specific locations in a room and recall them later.
