Number Path

Place 1 to the last number once each. Every number touches the one before it, along an edge or a corner.

Get PuzzlestackThe 1.1.0 release is finishing. The source is public today.

How to play

Tap an empty cell to write the next number. Tap a number you wrote to clear it. The hint button writes one number the printed clues prove.

  1. Find the 1. The cell that holds it touches the 2, so an isolated corner with one way in usually fixes its neighbour.
  2. Work from both ends. The lowest and highest printed numbers fix their own neighbours, and the walk closes in from the middle.
  3. A number only ever moves one cell, so a cell with eight neighbours can hold anything, and a corner cell can only hold numbers whose neighbours are near.
  4. When a printed number has only one free cell beside it, the number after it goes there. Write it; that closes one more door.
  5. The board is finished when every number is on it and every step touches the step before. A number out of reach shows in red.

Strategy

  • Count room, not hope: if the next number has nowhere to go from a cell, that cell cannot hold this one.
  • A cell that touches only one empty cell is the end of the path from that side, which pins both of its neighbours.
  • Long printed runs already laid out are free deductions: every gap between two printed numbers is a mini path with fixed ends.
  • When the grid fills up, the last few numbers place themselves: the cells left are the numbers left, in order.

What it asks of you

Place 1 to the last number on the grid, once each, so that every number touches the one before it and the one after it, along an edge or a corner.

Questions

Is Number Path free?

Yes. Puzzlestack is free to download, with no advertising, no account and nothing collected about you. Every puzzle can be played at least once.

How long does one Number Path take?

A few minutes at the size it opens; bigger boards are in the library.

Do I have to guess in Number Path?

No. Where a puzzle has one answer, the generator proves it before dealing, and the clues are enough to get there by reasoning.

What does Number Path practice?
