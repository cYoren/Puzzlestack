Shadow Pivot

Predict the shadow cast by a 3D object as it rotates on different axes.

Play Shadow PivotRuns in your browser, nothing to install.

How to play

Swipe to rotate the object or tap to select the matching shadow.

  1. Observe the 2D shadow cast on the wall.
  2. Examine the 3D objects available.
  3. Visualize how each object would cast a shadow from different angles.
  4. Select the object that matches the shadow perfectly.

Strategy

  • Focus on distinct edges and asymmetric features of the shadow.
  • Mentally rotate the objects on the X, Y, and Z axes.
  • Eliminate options that have features completely missing in the shadow.

What it asks of you

Identify the correct 3D object or orientation based on its projected 2D shadow.
