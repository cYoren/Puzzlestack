Triplets Trio

Fill the grid with three shapes, avoiding three-in-a-row. Every row and column must contain the same number of each shape.

Play Triplets TrioRuns in your browser, nothing to install.

How to play

Tap a shape tool to select it, then tap an empty cell on the grid to paint that shape. Tap a filled cell with the same tool to clear it.

  1. Select a shape from the tool menu below the grid.
  2. Tap an empty cell to place the selected shape.
  3. Use logic to ensure no three identical shapes are adjacent vertically or horizontally.
  4. Ensure every row and column contains exactly two of each shape to complete the puzzle.

Strategy

  • If you see two identical shapes next to each other, the spaces on either side MUST be different shapes.
  • If a row already has two of a certain shape, fill the remaining empty cells with the other shapes.

What it asks of you

Fill a 6x6 grid with three types of shapes so that every row and column has exactly two of each shape, and no three identical shapes appear consecutively in any row or column.
