Four Letters

Place A, B, C, or D to match the edge counts.

Play Four LettersRuns in your browser, nothing to install.

How to play

Tap a cell to cycle its letter: empty, then A, B, C, D, and back to empty. The hint button fills one cell the counts prove.

  1. Read one row's clue as four digits in alphabet order. On a five-cell row, `2111` means two As, one B, one C and one D.
  2. When a clue digit is met, that letter cannot appear again in the line. When the cells left in a line equal the counts still owed, those cells are fixed.
  3. Two identical letters may not share an edge, so a letter in a cell rules itself out of the cells above, below, left and right.
  4. Work the tightest line first: a line with a 0 or a line whose counts are almost used up is where the next certain letter is.
  5. The grid is finished when every cell holds a letter and every clue digit is met; a letter touching its twin is shown in red.

Strategy

  • A row whose clue has a 0 removes that letter from the whole row at once.
  • If a letter's count in a line equals the number of free cells, every free cell of that line is that letter.
  • Alternate thinking: a run of cells that can hold a letter at most every other cell bounds that letter's count. When the bound equals the clue, the alternation is forced.
  • Column and row clues cross, so a letter forced in a row very often fixes a cell in a column too. Sweep both directions each time you place one.

What it asks of you

Write one letter in every cell so that each row and column holds exactly the number of each letter printed beside it, and no two identical letters touch along an edge.

Questions

Is Four Letters free?

Yes. Puzzlestack is free to download, with no advertising, no account and no personal data collected. Every puzzle can be played at least once.

How long does one Four Letters take?

A few minutes at the size it opens; bigger boards are in the library.

Do I have to guess in Four Letters?

No. Where a puzzle has one answer, the generator proves it before dealing, and the clues are enough to get there by reasoning.

What does Four Letters practice?

It is a logic puzzle: write one letter in every cell so that each row and column holds exactly the number of each letter printed beside it, and no two identical letters touch along an edge.
