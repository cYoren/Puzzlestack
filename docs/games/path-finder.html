Path Finder

Find the hidden path from S to E.

Play Path FinderRuns in your browser, nothing to install.

How to play

Drag your finger across the grid to draw the path from start to finish.

  1. Identify the start (S) and exit (E) points on the grid.
  2. Note the required step length provided in the hint.
  3. Drag through the grid cells to create a path of the exact length.
  4. Connect the path to the exit point to complete the level.

Strategy

  • If you reach the exit too early, you need to find a more winding route.
  • Keep track of the number of steps as you drag.
  • Work backwards from the exit to find valid path segments.

What it asks of you

Trace a continuous path of a specific length from the start point to the exit point without overlapping.
