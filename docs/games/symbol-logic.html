Symbol Logic

Find each symbol's value to solve the final line.

Play Symbol LogicRuns in your browser, nothing to install.

How to play

Use the number pad to type your answer for the final equation. Tap the clear button to erase, and the checkmark button to submit your guess.

  1. Look at the first equation to determine the value of the first symbol (e.g., A + A = X).
  2. Use that value in the next equation to solve for the second symbol.
  3. Continue substituting known values to find the value of all symbols.
  4. Calculate the sum of the symbols in the final equation and enter the answer.

Strategy

  • Always start with the equation that has two identical symbols.
  • Write down the values of the symbols if you have trouble keeping them in memory.

What it asks of you

Deduce the numerical value of different symbols based on a series of visual equations, then calculate and input the answer for the final question.

No. Where a puzzle has one answer, the generator proves it before dealing, and the clues are enough to get there by reasoning.
