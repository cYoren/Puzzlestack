Common Denominator

Find the Greatest Common Divisor or Least Common Multiple.

Get PuzzlestackThe 1.1.0 release is finishing. The source is public today.

How to play

Type or select the correct number and submit.

  1. A set of fractions is displayed.
  2. Identify the denominators of all fractions.
  3. Calculate the lowest common multiple of these numbers.
  4. Enter your answer to complete the round.

Strategy

  • Check if the largest denominator is already a multiple of the others.
  • Use prime factorization for larger numbers.
  • Practice your multiplication tables to speed up calculation.

What it asks of you

Find the lowest common denominator (LCD) for a given set of fractions.
