Typoglycemia Decoder

Unscramble and read jumbled sentences speedily.

Get PuzzlestackThe 1.1.0 release is finishing. The source is public today.

How to play

Type the correct unscrambled word or select it from multiple choices.

  1. A word is displayed with scrambled inner letters (e.g. 'Tpyolgcyemia').
  2. Look at the first and last letters to grasp the word skeleton.
  3. Decipher the original word structure.
  4. Type or select the correct word to proceed.

Strategy

  • Read the word as a single entity rather than analyzing individual letter positions.
  • Focus on context if the word is part of a full sentence.
  • Your brain naturally recognizes words if the outer boundaries are correctly placed.

What it asks of you

Decipher and read words whose inner letters are scrambled, keeping only the first and last letters correct.
