Memory puzzles

Hold a pattern, then report it back. Short, fair, and over in a minute.

Memory games are played once and scored, so they are the shortest cards in the deck. A grid flashes, a sequence plays, then the board asks you what you saw. Nothing depends on a device being fast: the timer is yours.
